# Запуск на хостинге

В архиве лежит готовый Telegram-бот с договорами. Сначала распакуйте весь архив в одну папку на сервере.

## VPS или хостинг с Docker Compose

Требуется установленный Docker Engine с Docker Compose.

1. В папке проекта создайте файл .env, скопировав .env.example.
2. Вставьте токен от @BotFather после BOT_TOKEN= и сохраните файл.
3. Из этой папки выполните

```sh
docker compose up -d --build
```

Проверить работу

```sh
docker compose ps
docker compose logs --tail=30 bot
```

После запуска отправьте боту /start в Telegram. Контейнер будет перезапускаться после сбоя и перезагрузки сервера, если Docker запускается автоматически.

После загрузки обновлённых файлов повторите docker compose up -d --build. Для остановки выполните docker compose down.

## Хостинг с Python

Выберите сервис типа Background Worker / постоянный Python-процесс и Python 3.12.

Команда установки

```sh
pip install -r requirements.txt
```

Команда запуска

```sh
python bot.py
```

В переменных окружения хостинга создайте BOT_TOKEN и вставьте токен от @BotFather. Вместо переменной можно использовать файл .env рядом с bot.py.

Рабочая папка должна содержать bot.py, contracts.py, company_card.py, contracts.json и папку templates. Загрузите весь архив, чтобы сохранить структуру.

## Что учесть при запуске

Боту нужен доступ к api.telegram.org через HTTPS. Используется long polling. Домен и входящий HTTP-порт для этого процесса не требуются. Выберите хостинг, который позволяет запускать постоянный Python-процесс.

Одновременно запускайте один экземпляр для одного токена. Если бот уже работает на компьютере или другом сервере, остановите старый процесс. Если ранее был настроен webhook, удалите его перед переходом на polling.

Незавершённые анкеты хранятся в оперативной памяти и сбрасываются при перезапуске. Токен храните в настройках хостинга или в .env. Архив содержит пустой .env.example.

## Шаблоны договоров

В templates находятся демонстрационный договор и ВОИС для радиовещания. Список полей и пути к файлам описаны в contracts.json. Инструкция по редактированию шаблонов и распознаванию карточек компании находится в README.md.
